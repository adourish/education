Tie-breakers, in order

1. Managed beats self-managed. 2. Multi-AZ beats single-AZ. 3. Temporary credentials beat long-term keys. 4. A guard rail beats trusting people.
5. Cheaper wins only if every stated requirement still holds.
6. Reject the retired: EC2-Classic, Spot block, Classic Load Balancer, SWF.
7. Reject the impossible: a subnet spanning AZs, an EBS volume across AZs, a CNAME at the zone apex, reading a Multi-AZ standby.

Mnemonics

Six pillars — Operational Excellence, Security, Reliability, Performance Efficiency, Cost Optimization, Sustainability.
Trusted Advisor: CPFSS — Cost, Performance, Fault tolerance, Security, Service limits.
DR, cheapest first — Backup and restore, Pilot light, Warm standby, Multi-site active-active.
RTO = Time you may be down. RPO = Point in the past you fall back to.
Placement groups — Cluster = Close, Spread = Separate, Partition = Pods.
Default VPC gives five — internet gateway, main route table, security group, network ACL, DHCP option set.
Groups guard instances. Lists guard subnets. Default NACL is open; a custom NACL is closed.
Multi-AZ is durability. Read replicas are scalability.
Geolocation = the user. Geoproximity = your resources.
Streams if I write the consumer. Firehose if AWS writes it.
GuardDuty detects. Inspector scans. Macie classifies. Detective investigates. Security Hub collects.
CloudWatch watches performance. CloudTrail trails API calls. Config tracks configuration.
Beanstalk deploys the app. CloudFormation declares the infrastructure. OpsWorks is Chef and Puppet.
